## 🚀 Quick Setup

```

# 2. Enable Pages: Settings > Pages > GitHub Actions
# 3. Choose one: clone repo in VS Code OR create a Codespace from your repo
# Open a Local chat with Default Approvals, then run:
# /setup
```
